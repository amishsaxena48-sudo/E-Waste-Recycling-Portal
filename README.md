# ♻️ E-Waste Recycling Portal

An innovative full-stack web application designed to incentivize household electronic waste disposal through automated digital workflows and verified certificate generation. Built for the **AWS Environmental Hackathon**.

## 🌐 Live Demo
- **Live Website: https://e-waste-recycling-portal.edgeone.dev/

## 📌 Project Overview
The E-Waste Recycling Portal addresses the growing concern of improper household e-waste disposal by bridging the gap between consumers and certified recycling agencies. It features user authentication, structured e-waste logging, asset proof uploading, and an instant E-Certificate generator complete with unique tracking IDs and QR code verification. It is compatible to mobile and computers.

## 🛠️ Tech Stack & Architecture
- **Frontend:** HTML5, CSS3, JavaScript (Fully responsive UI/UX)
- **Deployment & Hosting:** EdgeOne (Global CDN distribution & secure HTTPS)
- **AWS Integration Roadmap:** Designed for seamless cloud scaling with AWS Amplify, AWS S3, and AWS DynamoDB in the next production phase.

## ✨ Key Features
- **User Authentication:** Secure sign-up and login workflow.
- **E-Waste Dashboard:** Category filtering and detailed item entry forms.
- **Proof Verification:** Upload utility for recycling handover receipts.
- **Instant E-Certificate:** Automatically generates a time-stamped Certificate of Appreciation with a unique tracking code (e.g., `EW-2026-xxxxx`) and scan verification.
- **Export Utility:** Print and PDF export support for generated certificates.
